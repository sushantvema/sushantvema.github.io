Langfuse the "the most used open-source LLM Engineering platform".

It is an observability and tracing layer for complex agents and multi-step
workflows.

It is based on [OpenTelemetry](https://opentelemetry.io/) (interoperable
observability standard for logging). Additionally it can be self-hosted, and it
API first

Some of the main value adds of the platform include:

- Visibility and explainability (`Langfuse Observability`)
- Cross-functional and cross-disciplinary collaboration (`Prompt Management`,
  `shareable view`)
